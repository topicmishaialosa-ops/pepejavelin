// IRC Chat - Примеры использования

// ============================================
// ПРОСТОЕ ОБЩЕНИЕ
// ============================================

// Отправка обычного сообщения
.msg Привет, как дела?  // через инвентарь

// ============================================
// КОМАНДЫ
// ============================================

// Показать справку
.help

// Очистить чат
.clear

// ============================================
// НАСТРОЙКИ ВЫГЛЯДА
// ============================================

// Смена цвета для себя
.color #FF0000     // красный
.color #00FF00     // зеленый
.color #0000FF     // синий
.color #FFFF00     // желтый
.color #FF00FF     // фиолетовый
.color #00FFFF     // голубой
.color #FFA500     // оранжевый
.color #FFC0CB     // розовый

// Смена ника
.nick CrackerUser
.nick CoolPlayer

// ============================================
// СПЕЦИАЛЬНЫЕ КОМАНДЫ
// ============================================

// Личное сообщение (системное уведомление)
.notice Привет! Это личное сообщение.

// Действие в стиле Discord
.me вайбует за кристаллы
.me тоже играет
.me только что заспавнился

// ============================================
// УПРАВЛЕНИЕ ЧАТОМ
// ============================================

// Переключение каналов
.join #общий
.join #pub
.join #game
.join #trash

// Выход из чата
.leave

// ============================================
// ПРИМЕРЫ СИСТЕМНЫХ СООБЩЕНИЙ
// ============================================

[Система] Добро пожаловать в IRC чат!
[Система] Напиши .help для списка команд
[Система] Вы вышли из IRC чата
[Система] Чат очищен
[Система] === Команды IRC ===
[Система] .help - эта справка
[Система] .clear - очистить чат
[Система] .color [название] - смена цвета
[Система] .nick [ник] - смена ника
[Система] .notice [сообщение] - личное сообщение
[Система] .me [сообщение] - действие
[Система] .leave - выйти из чата
[Система] .join [канал] - переключить канал

// ============================================
// ПРИМЕРЫ ИСПОЛЬЗОВАНИЯ
// ============================================

[Ваня] Привет всем! 👋
[Маша] Привет, Ваня! Как играешь?
[Ваня] Отлично! Только что взломал базу кристаллов 🎉
[Маша] Круто! Скинь мне конфиг?
[Коля] Я могу помочь с настройками! Пиши в личку .notice

// Системное сообщение
[Система] ◇ Новый пользователь присоединился: Коля

// Действие
[Система] * Ваня вайбует за кристаллы
[Система] * Маша тоже играет

// ============================================
// ТИПИЧНЫЕ СЦЕНАРИИ
// ============================================

// 1. Начало общения
.help
.color #FF0000
.nick NovaUser
.msg Привет! Я новичок в этом сервере, помогите, пожалуйста!

// 2. Нахождение команды
.join #game
.msg Привет! Кто играет на сервере?

// 3. Личное общение
.msg Привет! Мне нужна помощь с настройками

// 4. Уведомление
.notice Привет! Ты помнишь, что мы договаривались по поводу кристаллов?

// ============================================
// ВИЗУАЛЬНЫЕ ОСОБЕННОСТИ
// ============================================

// Цветовая кодировка имен
[<Ваня>] Привет! 👋     // красный (по умолчанию)
[<Маша>] Как дела?      // зеленый
[<Коля>] Я здесь! 🎉     // голубой
[<Система] ◇ Привет!    // серый

// Особенности отображения
• Системные сообщения с символом ◇
• Личные сообщения с обводкой ===
• Действия с префиксом *
• Каждый пользователь имеет свой уникальный цвет

// ============================================
// НАСТРОЙКА ИНТЕРФЕЙСА
// ============================================

// Полезные команды для настройки
.color #00FF00    // зеленый цвет
.nick Player123   // новый ник
.join #pub        // переключиться на публичный канал
.clear            // очистить чат перед важным сообщением

// ============================================
// ПРОБЛЕМЫ И РЕШЕНИЯ
// ============================================

// Проблема: Не видны системные сообщения
 Решение: .clear - очистить чат

// Проблема: Не понимаю команды
 Решение: .help - справка

// Проблема: Хочу другой цвет
 Решение: .color #RRGGBB - смена цвета

// Проблема: Перепутал канал
 Решение: .join #канал - переключиться

// ============================================
// РЕКОМЕНДАЦИИ
// ============================================

1. Используй .help чтобы узнать все команды
2. Не спамь канал сообщениями
3. Используй .clear чтобы очистить старые сообщения
4. Меняй цвет (.color) для удобства чтения
5. Пользуйся .notice для личной переписки
6. Избегай токсичных сообщений
